# Boschert Technologies branding

These are copies of the original artwork supplied by Boschert Technologies in
`Documents/Boschert Technologies/Art`. The original files have not been modified.

- `BoschertTechnologiesMark.png`: original transparent black company symbol.
- `BoschertTechnologiesWordmark.png`: original combined symbol and company name.
- `BoschertTechnologiesMark.svg`: original vector company symbol.

The app window uses the symbol as a template image so it remains legible in light
and dark appearances. `BuildIcon.swift` places the original symbol on a neutral
application-icon background. The app icon also appears in the standard About
dialog and Dock.
